# Travely Widget WordPress Plugin

## Установка

1. Скачайте архив с плагином (`travely-widget.zip`) из [релизов GitHub](https://github.com/Travely-ee/travely-widget-wordpress/releases).
2. Войдите в админ-панель WordPress.
3. Перейдите в раздел **Плагины → Добавить новый → Загрузить плагин**.
4. Загрузите архив и активируйте плагин.

## Настройка

1. Создайте новую страницу с шорткодом `[travely-widget-results]` для отображения результатов поиска.
2. Перейдите в раздел **Настройки → Travely Widget** для настройки виджета. Введите ваш API ключ и адрес страницы с результатами поиска.

## Использование 

Используйте шорткоды `[travely-widget-search]`, `[travely-widget-country]`, `[travely-widget-best]` в любой записи или странице, чтобы отобразить виджеты Travely.

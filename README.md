# Travely Widget WordPress Plugin

## Установка

1. Скачайте архив с плагином (`travely-widget.zip`) из [релизов GitHub](https://github.com/Travely-ee/travely-widget-wordpress/releases).
2. Войдите в админ-панель WordPress.
3. Перейдите в раздел **Плагины → Добавить новый → Загрузить плагин**.
4. Загрузите архив и активируйте плагин.

## Использование

После активации плагина используйте шорткод `[travely_widget]` в любой записи или странице, чтобы отобразить виджет Travely.
